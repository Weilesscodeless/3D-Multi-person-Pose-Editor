# 00213 侧视拥抱攻坚 · 脸种子 SAM2 分离与编辑器落位（2026-10-04）

## 背景与结论

侧视紧抱两人在 2D 检测层是死角：DWPose 并成 1 人、YOLO 实例分割两掩膜彼此包含（IoU 高达 0.9）、GaoshangYoloMaskedCrops 的掩膜不分离导致两人重建相同再去重成 1 人。本轮打通**脸种子 SAM2 分离链**，端到端稳定输出 2 个独立人偶；随后修掉编辑器落位的单位错配与被遮挡者缩水问题。全部用数字验证（掩膜 IoU、投影-分割对齐度、骨长、反跑 DWPose 计人数），代理不看图。

## 检测链终态

```
照片 → face_yolov8m 检脸（models/ultralytics/bbox/）
    → 每脸一正点 + 其余脸负点 → SAM2 multimask 三候选
    → 取「含自己脸心、不含任何他人脸心、面积最大」= 全身掩膜（00213 实测两人 IoU 0.0039）
    → 逐人涂黑他人整帧 batch + 逐帧单框 list[list[box]]
    → SAM3DBody_Predict 逐人重建（MHR_POSE_DATA frames=每人一帧一人）
    → GaoshangMHRToOpenPose
        · frames 拍平（逐帧单框批次每帧一人，只读 frames[0] 会丢人）
        · 图像空间去重（重心 X<9%W 且 Y<14%H=同人）+ cam_t 兜底（半径 0.1m；0.3m 会误杀紧抱真人）
        · 同平面 λ=z*/z_i 定尺（z*=组内 cam_t z 中位数；投影不变）
        · world_pos=[cam_t.x×λ, 0, z*]（共享相机系真实站位，米）
        · fully_visible（掩膜高/脸高∈[5,8] = 全身可见 = 重建可信）
    → input/gaoshang_openpose/sam3d_multi.json（+face_crops.json 掩膜几何）
    → FreePose 编辑器「按 SAM3D 重摆」
```

工作流：`高尚姿势\高尚-姿势工具台-编辑与双路输出-自由姿势版-脸种子版.json`（80=DownloadAndLoadSAM2Model base_plus/single_image/cuda/fp16，82=GaoshangFaceSeedCrops 顶替 MergeBboxes，61.image 吃掩膜批次）。

## 设计原则（用户拍板，三条）

1. **不用任何身体部位启发式定大小**（脸框会截断、侧抱半张脸、头身比不可靠——中途废弃过掩膜定高与头身比估高两版）。
2. **几何投影是唯一裁判**：SAM3D 模型的 2D 投影所见即所得，2D 数据一字不改写。
3. **单目尺度不确定 → 同平面假设固定尺度**：远处大人 ≡ 近处小人的多解性，两人基本同平面（紧抱/并排）是唯一几何规尺——3D 骨架按 λ=z\*/zᵢ 等比缩放，投影分毫不动，两组骨架同深度下尺度可比。

## 编辑器落位（freepose v40）

- **单位错配（最大坑）**：`transform.x/z` 是 MakeHuman 网格原生单位，实测网格 bbox 高 **14.33 单位**（≈1 分米/单位），米制直接填会小 8 倍（人偶 13 单位高、间距 1.6 单位=贴脸粘连）。落位处按 **UNITS_PER_METER=8.2** 换算（x/z 都换算，随各自 zoom 缩放，clamp ±20）。
- **站位**：world_pos 真实横向直接采用（不做最小间距拉开——紧抱就呈现紧抱）。各图真实横距（同平面归一后中心距）：Krea2 0.42m / 00213 0.25m / 00096 0.36m / 00188 0.34m。
- **大小**：可见者（fully_visible=true）保留各自投影 zoom；**被遮挡者 zoom 采用组内可见者最大基准**——实测被遮挡者 SAM3D 骨架整体缩水（00096 骨长和 3.47 vs 5.34m、躯干 0.46 vs 0.72m、骨长比 0.65≈投影比 0.68，是重建缩水不是姿势压扁）。00213 双人都可见 → 保留 0.92/1.1（右人确实更近）。
- **同距判定**：组内 cam_t z 差 <0.6m → z=0 不做透视反推；纵深差大的合影仍走近大远小。
- **入口状态保护（v22 设计）**：编辑器有已保存状态时永不自动导入，出口=「按 SAM3D 重摆」按钮（现取 `/gaoshang_pose/sam3d_multi`，全量新逻辑）。

1. 跑工作流（写 sidecar）→ 2. 打开 FreePose 编辑器 → 3. 点**「按 SAM3D 重摆」** → 4. 微调 → 5. 应用 → 6. 再跑出成品。

## 已知问题（如实暴露，不掩盖）

- **被遮挡者姿势拟合不足**：00188 左人投影仅 360px < 自身可见 470px——SAM3D 对涂黑遮挡图的姿势拟合质量问题（大小已由可见度基准修正，姿势本身仍偏小）。下一步方向：补负点重分割/换裁剪策略。
- cam_t 绝对深度有 ±20% 量级不确定度（单目固有）；同平面规尺已消除组内相对误差。
